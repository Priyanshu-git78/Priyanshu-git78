## 🌟 Featured Projects
 
### 🎥 [AI-Powered Intelligent Security Ecosystem](https://github.com/Priyanshu-git78/Computer-Vision-CCTV-Tracking) — Computer Vision / CCTV Tracking
Real-time YOLO object detection with multi-object tracking (ByteTrack, BoT-SORT) turning CCTV feeds into security and customer-behavior analytics. Benchmarked 7 training strategies and 2 trackers on latency, CPU load, and accuracy to select the best detector/tracker pair for deployment.
`YOLOv8` `ByteTrack` `BoT-SORT` `FastAPI` `WebSockets` `PostgreSQL`
 
### 📄 [OmniParse-RAG](https://github.com/Priyanshu-git78/OmniParse-RAG) — Multimodal RAG System · [Live Demo](https://omniparse-rag.streamlit.app/)
Hybrid-retrieval RAG over PDFs, Excel, PPT, and diagrams. Dense similarity search (pgvector + MMR) fused with BM25 keyword search via Reciprocal Rank Fusion, then cross-encoder reranked before generation through an OpenAI-compatible API.
`pgvector` `MMR` `BM25` `RRF` `Cross-Encoder` `LangChain` `FastAPI`
 
### 📊 [Sales Forecasting](https://github.com/Priyanshu-git78/sales-forecasting-regression) — Predictive Analytics for Business Planning
22-feature regression pipeline (lag values, rolling averages, seasonal encoding) benchmarking Linear Regression, Random Forest, XGBoost, and Gradient Boosting — cut forecast error (MAE) 69% (120K → 37K).
`XGBoost` `Gradient Boosting` `Scikit-learn` `Pandas`
 
### 🧪 AI Benchmark Framework — Open-Source vs. Closed-Source LLM Evaluation *(MBA Capstone)*
Benchmarked 6 LLMs (GPT-5, Claude Opus, Gemini Pro, Llama, Qwen, Mistral) across 8 weighted dimensions including intelligence, cost efficiency, and security. Modeled Total Cost of Ownership across usage tiers to find the open-source break-even point at enterprise scale.
`Python` `LLM Evaluation` `Excel Automation`
